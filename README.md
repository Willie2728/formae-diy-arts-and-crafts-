## Core product direction

FORMAE is a personal creative studio for starting, documenting, developing, rendering, organizing, and sharing DIY art projects by voice, text, image, file upload, camera capture, and browser reference. It includes persistent project memory, dated projects, autosave controls, categories, AI creative assistance, image/render generation, import/export/share flows, and future photo-rigged avatar support.

Brand direction: deep red and metallic gold, premium sculptural identity.
